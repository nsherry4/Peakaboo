Peakaboo Mono
=============

A modified version of JetBrains Mono 2.211 by The JetBrains Mono Project
Authors (https://github.com/JetBrains/JetBrainsMono), under the SIL Open Font
License 1.1 (OFL.txt). The original authors have not endorsed this version.

Changes: renamed to Peakaboo Mono; the prep table was removed and the gasp
table replaced so Java renders it antialiased without grid-fitting. Outlines,
metrics and all other tables are unchanged.
