Peakaboo Chart Sans
===================

Peakaboo Chart Sans is a modified version of TeX Gyre Heros, and is not TeX
Gyre Heros itself. The authors of TeX Gyre Heros are not responsible for these
changes and have not endorsed this font.

  Authors:   Bogusław Jackowski and Janusz M. Nowacki, with Vietnamese

Changes
-------

  1. Renamed to Peakaboo Chart Sans (files, name table and CFF names).
     Copyright and trademark notices are unchanged.
  2. A gasp table was added so Java renders the text antialiased without
     grid-fitting.

Outlines, metrics, kerning and character coverage are unchanged.
