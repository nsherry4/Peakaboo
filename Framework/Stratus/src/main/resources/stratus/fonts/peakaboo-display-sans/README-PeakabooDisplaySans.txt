Peakaboo Display Sans
=====================

A modified version of DejaVu Sans 2.35 by the DejaVu fonts team, based on
Bitstream Vera (https://github.com/dejavu-fonts/dejavu-fonts), under the
licences in LICENSE-DejaVu.txt. It is renamed as that licence requires of
modified versions. The DejaVu fonts team has not endorsed this version.

Changes: the hinting program was removed from each glyph (the font-wide hinting
tables are kept), and the font was renamed to Peakaboo Display Sans. Outlines,
metrics and kerning are unchanged.
